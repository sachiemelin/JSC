# CO Monitoring DKI Jakarta

Monitoring Carbon Monoxide (CO) di Jakarta menggunakan data Sentinel-5P melalui Google Earth Engine.

## 📊 Deskripsi

Script ini menganalisis konsentrasi CO di wilayah DKI Jakarta dari Januari - April 2023 menggunakan data satelit Sentinel-5P Level 3.

## 🚀 Fitur

- ✅ Visualisasi data CO pada peta
- ✅ Time series chart CO harian
- ✅ Legend dengan color palette
- ✅ Export data ke GeoTIFF

## 📥 Cara Pakai

1. Buka di Google Earth Engine: https://code.earthengine.google.com/?accept_repo=users/sachiemelin/JSC
2. Jalankan script `CO_DKI_Analysis.js`
3. Lihat hasil di map dan console
4. Export data di tab Tasks

## 📁 File

- `CO_DKI_Analysis.js` - Main script untuk analisis CO

## 📚 Data Source

- Sentinel-5P NRTI L3 CO: https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S5P_NRTI_L3_CO
- Boundary DKI: Asset pribadi
